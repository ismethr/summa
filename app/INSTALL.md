## 1. 安装与打开

应用位置：

```
~/Applications/Summa.app
```

打开方式，任选其一：

- 打开「启动台」，搜索 **Summa**
- 打开「访达」，按 `⌘ ⇧ G`，粘贴 `~/Applications`，双击 Summa
- 终端执行 `open ~/Applications/Summa.app`

想放进程序坞：打开后右键程序坞里的图标 → 选项 → 在程序坞中保留。

首次打开如果提示「无法验证开发者」：右键点图标 → 打开 → 再点一次「打开」。之后不会再问。本机编译的应用一般不会触发这个提示。

## 2. 第一次使用：配置 API Key

Summa 用 DeepSeek 读论文，需要你自己的 API Key。

1. 到 [platform.deepseek.com](https://platform.deepseek.com) 登录，在「API Keys」页面创建一个 Key，并确认账户有余额
2. 打开 Summa，点右上角的「未配置 API Key」（或左下角「设置」）
3. 粘贴 Key，点「测试连接」，看到绿色的「连接成功，Key 有效」
4. 点「保存」。立刻生效，不用重启

配好后右上角会显示绿点和模型名 `deepseek-flash`。

**关于模型**：默认的 `deepseek-flash` 能读图，一般不需要改。`deepseek-v4-pro` 不支持图像，不能用。

**Key 的安全**：Key 只保存在本机的 `config.json` 里，界面上只显示首尾几位（如 `sk-ab••••wxyz`），不会出现在界面代码中。

## 3. 解析论文

把 PDF 文件从访达**拖进 Summa 窗口**，松开。

- 可以一次拖入多篇，会逐篇排队，进度框里显示「还有 N 篇排队」
- 每篇经历四步：读取文件 → 渲染页面 → 模型解析 → 入库，一般几十秒
- 完成后自动选中新文献，显示它的要义页
- 只接受 `.pdf`，单个文件不超过 80 MB
- 扫描版 PDF 也能解析，因为模型直接读页面图像

**某篇失败了**：错误框会说明原因（Key 无效、余额不足、网络不通、超时等）。如果后面还有排队的，点「跳过，继续下一篇」。

**同一个文件再拖一次**：会重新解析并覆盖旧记录，不会出现两条；你标的星标、已读和笔记会保留。

**解析了什么**：只看前 12 页。正文一般都在这个范围内，附录和很靠后的补充实验不会被读到。

## 4. 阅读要义页

右侧的要义页由上到下是：

| 部分 | 内容 |
|---|---|
| 标题与署名 | 作者、期刊/会议、年份；外部导入的还有 DOI 和「来自 workbuddy」标记 |
| 操作按钮 | 星标、标为已读、复制引用、打开 PDF、删除 |
| 主题 | 这篇所属的主题，可直接编辑 |
| 一句话要旨 | 蓝色框，这篇做了什么、结果如何 |
| 研究问题 | 作者要解决什么 |
| 方法路径 | 编号的几个步骤 |
| 关键发现 | 最多几个关键数字及其含义 |
| 局限与适用边界 | 只收作者自己承认的局限，用来判断能否用在你的场景 |
| 我的笔记 | 你自己的想法 |

**关于数字**：模型被要求逐字照抄原文数值、看不清就留空（显示为「—」）。重要的数字，引用前建议点「打开 PDF」回原文核对。

**复制引用**：复制一条简化的 APA 格式，例如 `Chen, L., Wang, Y. (2025). 题名. IEEE TGRS.`，可直接粘贴进文档。

**打开 PDF**：用系统的「预览」打开库里保存的那份 PDF。

## 5. 整理文献

### 主题

主题由模型解析时自动给出，你可以随时调整：

| 想做的事 | 操作 |
|---|---|
| 给一篇加主题 | 要义页主题行点「+ 主题」，输入后回车（会提示库里已有的主题） |
| 从一篇上去掉主题 | 点主题旁的 × |
| 重命名主题 | 双击左侧主题名，改完回车（Esc 取消） |
| 合并两个主题 | 双击其中一个，改成另一个的名字 |
| 删除主题 | 鼠标移到左侧主题上，点 ×，再点「移除主题？」 |

删除主题只是把它从各篇文献上去掉，**文献本身不会被删**。

建议：篇数多了以后，模型可能给出「变化检测」「SAR 变化检测」这类近义主题，用合并把它们归成一个。

### 已读、星标

- 要义页上点「标为已读」/「☆ 星标」切换
- 列表里未读的标题前有蓝点，星标的有 ★
- 左侧「待读」「星标」可以直接筛出来

### 我的笔记

在要义页最底部。输入后停顿不到一秒就自动保存（标题旁短暂显示「保存中…」）。笔记内容也能被搜索到。

### 批量操作

| 操作 | 方法 |
|---|---|
| 逐篇多选 | 按住 `⌘` 点击列表中的文献 |
| 连续选择 | 先选中一篇，按住 `Shift` 点另一篇 |
| 全选当前列表 | `⌘ A` |
| 取消选择 | `Esc`，或直接单击某一篇 |

选中两篇以上时，右侧变成批量操作面板：全部标为已读 / 待读、全部星标 / 取消星标、批量添加主题、批量删除。

### 删除文献

- 单篇：要义页右上角「删除」，再点「确认删除？」
- 多篇：多选后在批量面板里删除，同样要确认

删除会移除记录和库里保存的 PDF 副本，**你电脑上原来的 PDF 文件不受影响**。删除无法撤销。

## 6. 查找文献

### 搜索

标题栏的搜索框（`⌘ F` 直接跳过去）。匹配题名、作者、期刊、年份、主题、要旨、方法步骤和你的笔记。多个词用空格隔开，表示同时包含。`Esc` 清空。

### 筛选

- 左侧导航：全部文献、待读、星标、最近 7 天
- 左侧主题：点一下只看这个主题，再点一次取消
- 搜索、导航、主题可以叠加；列表上方显示「筛选结果 / 总数」，点「清除筛选」恢复

### 排序

列表上方的下拉框：最近添加、年份（新→旧）、题名（A→Z）。

## 7. 从 AI 工具导入

如果你在 WorkBuddy 里读论文，可以让它把读完的结果直接存进 Summa，不用再拖一次 PDF。

### 已经装好了

技能 `summa-import` 已安装在 `~/.workbuddy/skills/summa-import`。

### 怎么用

在 WorkBuddy 里读完或分析完一篇论文后，说：

> 存到 Summa

或「加进我的文献库」「归档一下」。WorkBuddy 会整理成要义页格式提交给 Summa。

- **Summa 开着**：几秒内出现在列表最上方，底部提示「已从外部工具导入」
- **Summa 没开**：先放进收件箱，下次打开 Summa 时自动导入
- **论文是本机的 PDF**：WorkBuddy 会一并附上，之后在 Summa 里能直接「打开 PDF」
- **同一篇导入两次**：按 DOI 或标题识别为同一篇，合并成一条；你的笔记、星标、已读状态不受影响

### 反过来：检索你的库

写论文或做综述时，在 WorkBuddy 里问：

> 我库里有没有关于 SAR 变化检测的文献？

它会检索你的 Summa 文献库，只回答库里真实存在的内容。

### 在 Claude Code 里也用

```bash
cp -R ~/.workbuddy/skills/summa-import ~/.claude/skills/
```

### 导入出错

格式有问题的数据不会进库，会放到数据目录的 `inbox/failed/`，旁边的 `.error.txt` 写着原因。WorkBuddy 通常会自己修正后重新提交。

## 8. 外观

- 标题栏右侧的太阳 / 月亮按钮：一键切换日间、夜间
- 设置 → 外观：「跟随系统」「日间」「夜间」三选一。选「跟随系统」后，macOS 切换浅色/深色时 Summa 自动跟着变

## 9. 快捷键

| 快捷键 | 作用 |
|---|---|
| `⌘ F` | 跳到搜索框 |
| `↑` `↓` | 切换上一篇 / 下一篇 |
| `⌘ A` | 全选当前列表 |
| `⌘` + 点击 | 多选 |
| `Shift` + 点击 | 连续选择 |
| `Esc` | 清空搜索 / 取消多选 / 关闭设置 |
| `⌘ Q` | 退出 Summa |

在输入框和笔记里打字时，`↑` `↓` 和 `⌘ A` 按正常编辑处理，不会切换文献。

## 10. 数据、备份与隐私

### 数据在哪

全部在这个文件夹（设置窗口底部也显示了这个路径）：

```
~/Library/Application Support/app.summa.desktop/
```

| 文件 / 文件夹 | 内容 |
|---|---|
| `library.json` | 全部文献记录，包括主题、笔记、星标、已读 |
| `files/` | 解析过的 PDF 副本（原文件移走或删掉也能打开） |
| `config.json` | API Key 和模型设置 |
| `inbox/` | AI 工具提交、等待导入的数据；`failed/` 里是格式有误的 |

### 备份

把整个 `app.summa.desktop` 文件夹复制一份即可。恢复时退出 Summa，把备份放回原处。

### 清空文献库

退出 Summa，删掉 `library.json` 和 `files/`，再打开就是空库。

### 什么会离开你的电脑

- **会上传**：解析时，PDF 前 12 页渲染成的页面图像，发给 DeepSeek
- **不会上传**：PDF 文件本身、你的笔记、星标、主题、文献库

## 11. 费用

Summa 本身免费，费用来自 DeepSeek 的 API 调用，直接从你的 DeepSeek 账户扣。按官方价格估算，每篇论文不到 0.1 元，以 DeepSeek 账单为准。

- 从 AI 工具导入不调用 Summa 的模型，不产生 Summa 侧的费用
- 「测试连接」只查询模型列表，不消耗 token

## 12. 更新与卸载

### 更新

从源码重新打包并替换（约 1–2 分钟）：

```bash
cd ~/Claude/wenxian/app && npm run tauri build && rm -rf ~/Applications/Summa.app && cp -R src-tauri/target/release/bundle/macos/Summa.app ~/Applications/
```

更新前先 `⌘ Q` 退出 Summa。文献数据不在应用里，更新不会丢失。

### 卸载

把 `~/Applications/Summa.app` 拖进废纸篓。如果连数据也不要了，再删除 `~/Library/Application Support/app.summa.desktop/`。

## 13. 常见问题

**拖入 PDF 没反应**
确认拖的是 `.pdf` 文件，并在 Summa 窗口内松开。出现「松开以解析」的遮罩才说明 Summa 收到了。

**提示「还没有配置 DeepSeek API Key」**
按[第 2 节](#2-第一次使用配置-api-key)配置。

**提示「API Key 无效」**
Key 填错或已被删除。打开设置重新粘贴，先「测试连接」再保存。

**提示「账户余额不足」**
到 DeepSeek 平台充值。

**提示「请求超时」或「连不上 DeepSeek」**
检查网络后重新拖入。Summa 等待模型最多 5 分钟。

**提示「模型没有返回可解析的 JSON」或「字段结构不符」**
模型偶尔输出格式不对，重新拖入一次通常就好。反复出现请把错误框里的文字发给开发者。

**数字和原文对不上**
模型可能看错，用「打开 PDF」核对原文，在笔记里记下正确值。

**「打开 PDF」按钮不见了或提示找不到文件**
这条记录没有保存 PDF 副本（例如 AI 工具导入时没附 PDF）。把原 PDF 拖进来解析一次即可补上。

**WorkBuddy 说已导入，但列表里没有**
看左侧是否处在「待读」「星标」或某个主题的筛选下，点「清除筛选」。

**窗口拖不动**
拖标题栏的空白处。搜索框和右侧按钮所在的位置不能拖动窗口。

**窗口一片空白**
`⌘ Q` 完全退出后重开。

## 14. 目前的限制

- 只解析前 12 页
- 搜索是关键词匹配，不懂近义词：搜「无监督」找不到只写了「self-supervised」的论文
- 删除不能撤销，重要数据请定期备份
- 只在 macOS 上实测过
- 文献达到几千篇后，加载和保存可能变慢
