# Summa 品牌与命名基线

> 状态：已定稿（2026-10-27）
> 本文是产品对外命名、文案与商标工作的唯一事实源。任何新增模块名、功能名均在此登记。

---

## 1. 主名称

| 项目 | 内容 |
|---|---|
| 正式名称 | **Summa** |
| 中文名 | **文渊**（对外传播、中文界面品牌位） |
| 读音 | 英文 /ˈsʊmə/（苏-玛），中文俗读「苏玛」 |
| 词源 | 拉丁语 *summa*，意为「总和、总括」 |
| 典出 | *Summa Theologiae* 体例——将整个知识领域收拢为一部有结构的书 |
| 字母数 / 音节 | 5 / 2 |

### 语义锚点

Summa 指的是**把分散的文献收拢成有结构的要义**，而非「收藏、归档」。这一点决定了产品的语言体系：所有文案谈「提炼、收拢、要义、结构」，不谈「存储、管理、剪藏」。

这是与 Zotero / Mendeley 的根本区分——它们在解决「存不下」，Summa 解决「读不完」。

---

## 2. 产品线命名体系

主品牌不拆分，子产品采用 `Summa + 功能词` 的后缀式，避免再造词。

| 形态 | 名称 | 说明 |
|---|---|---|
| 桌面主应用（macOS / Windows） | **Summa** | 拖入文献、解析、归类、总结的主场 |
| 移动端 | **Summa Pocket** | 只读与速览，不做完整编辑 |
| 浏览器扩展 | **Summa Clip** | 网页与 DOI 一键入库 |
| 团队协作版 | **Summa Teams** | 共享文库、共用主题体系 |
| 开放接口 | **Summa API** | 供第三方与自动化脚本调用 |
| 本地模型模式 | **Summa Local** | 全部推理在本机完成，不上传原文 |

---

## 3. 内部术语（界面用词）

统一术语，避免同义词泛滥。

| 概念 | 用词 | 禁用 |
|---|---|---|
| 单篇文献的 AI 摘要页 | **要义页 / Synopsis** | 摘要、summary、卡片 |
| AI 自动生成的分类 | **主题 / Theme** | 标签、文件夹、分类 |
| AI 提取的研究内容 | **研究问题** | 研究内容、主题内容 |
| AI 提取的方法 | **方法路径** | 技术路线、方法论 |
| 用户手动拖入的动作 | **投递 / Drop** | 导入、上传、新增 |
| 解析状态 | **解析中 / 已总括** | 处理中、分析完成 |

---

## 4. 文案与语气

- **定位语（英文）**：*Read less. Know more.*
- **定位语（中文）**：**一页见要旨**
- **一句话介绍**：把文献拖进 Summa，它替你读完，并告诉你这篇写了什么、怎么做的、值不值得读。
- **语气**：学术、克制、不喧哗。不用感叹号，不用「智能革命」「颠覆」一类词。研究者对夸大表述的容忍度极低，这一点直接影响信任建立。

## 6. 视觉方向（已定稿：B · 现代 AI）

2026-10-27 决策：采用 **B 方案**。A 方案（学术沉稳，衬线 + 纸白 + 赭红）保留为备选，不进入实施。

### 设计令牌

| 类别 | 令牌 | 值 |
|---|---|---|
| 页面底 | `--bg` | `#0C0C0F` |
| 侧栏 | `--panel` | `#08080B` |
| 列表 | `--list` | `#0D0D11` |
| 阅读区 | `--detail` | `#101015` |
| 卡片 | `--card` | `#16161E` |
| 卡片（强调） | `--card2` | `#1D1D27` |
| 主文字 | `--ink` | `#F2F2F5` |
| 次文字 | `--ink2` | `#9898A4` |
| 弱文字 | `--ink3` | `#5A5A66` |
| 分隔线 | `--line` | `#23232D` |
| 强调色 | `--accent` | `#7C8CFF` |
| 成功/完成 | `--ok` | `#35D0A8` |
| 圆角 | 小 / 中 / 大 | 7px / 11px / 14px |
| 字体 | 全局 | 系统无衬线（SF Pro / PingFang SC） |
| 等宽 | 日志 | `ui-monospace, SFMono, Menlo` |

**层级原则**：深色界面靠「亮度递增」表达纵深，而非阴影。底色 → 面板 → 卡片 → 强调卡片，四级亮度差约为 4–6 个亮度单位，过大会显脏，过小会糊。

**强调色使用纪律**：`#7C8CFF` 只用于三类位置——当前选中项、可点击的主操作、AI 生成内容的标识。全屏出现超过四处的蓝紫即为过度使用。

### 版式结构

三栏固定：侧栏 224px（导航 + 主题）／列表 330px（文献条目）／阅读区自适应（要义页，正文最大宽度 660px）。

阅读区限宽是为了控制行长——中文正文单行超过 40 字，回扫就会开始丢行。这是可读性的硬约束，不是审美选择。
